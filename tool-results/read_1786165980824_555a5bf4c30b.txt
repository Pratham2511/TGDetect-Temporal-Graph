   446→            <p><strong>Here is a simplified explanation of the entire workflow:</strong></p>
   447→            <p><strong>Step 1 &mdash; Data Collection:</strong> Five types of logs are collected from the system: authentication logs (who logged in), system audit logs (what processes ran), network flow data (what network connections were made), DNS query logs (what domains were looked up), and cloud API logs (what cloud actions were taken).</p>
   448→            <p><strong>Step 2 &mdash; Graph Construction:</strong> Each unique entity (user, process, file, IP address, domain) becomes a NODE in the graph. Each action or event between entities becomes a timestamped EDGE. For example, if &ldquo;User A&rdquo; executed &ldquo;Process B&rdquo; at &ldquo;10:30 AM&rdquo;, there would be an edge from User A to Process B with timestamp 10:30.</p>
   449→            <p><strong>Step 3 &mdash; TGNN Processing:</strong> The temporal graph neural network processes this graph. It uses <strong>time encoding</strong> (converts timestamps into mathematical patterns using sine/cosine functions), <strong>message passing</strong> (nodes exchange information with their neighbors), <strong>temporal aggregation</strong> (combines information over time), and <strong>entity memory</strong> (remembers what each entity did historically).</p>
   450→            <p><strong>Step 4 &mdash; Detection:</strong> The TGNN classifies each event as normal or malicious based on patterns it learned during training.</p>
   451→            <p><strong>Step 5 &mdash; LLM Explainability:</strong> When an attack is detected, the LLM generates a human-readable explanation like: &ldquo;At 2:15 PM, an authenticated user executed a PowerShell script that connected to an external IP address. This script then accessed the SAM database, which is consistent with credential dumping behavior seen in APT attacks.&rdquo;</p>
   452→            <p><strong>Step 6 &mdash; Concept Drift:</strong> The system continuously monitors if the data patterns are changing over time (new attack techniques, new software versions, etc.) and re-trains or adapts its models accordingly.</p>
